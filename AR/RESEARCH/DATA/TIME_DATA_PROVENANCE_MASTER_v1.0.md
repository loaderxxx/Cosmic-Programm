# قاعدة الوقت والبيانات والمنشأ المجمعة v1.0

## الغرض

إنشاء مبدأ موحد لمنشأ البيانات التقنية للبرنامج.

## الحد الأدنى لسجل القياس

- المعرّف؛
- الوقت؛
- المقياس الزمني؛
- المصدر؛
- المركبة؛
- النظام الفرعي؛
- المستشعر؛
- التهيئة؛
- الوحدات؛
- القيمة الخام؛
- القيمة المعالجة؛
- خوارزمية المعالجة؛
- إصدار البرمجيات؛
- الجودة؛
- عدم اليقين.

## المنشأ

يجب أن يتيح كل استنتاج تقني منشور تتبع السلسلة:

**المصدر ← الاستخراج ← التوحيد ← الحساب أو المعالجة ← النتيجة ← وثيقة البرنامج.**

## الإصدارات

يجب ألا يغيّر تعديل معامل إدخال استنتاجاً سابقاً بصمت. تُحفظ النتيجة السابقة مع إصدارها وسبب التغيير.

## المبدأ

البيانات بلا منشأ لا تصبح حقيقة هندسية لمجرد أنها تبدو معقولة.

الحالة: خط أساس (BASELINE).
