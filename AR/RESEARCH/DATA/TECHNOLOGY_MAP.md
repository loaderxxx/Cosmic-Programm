# الخريطة العالمية لتقنيات الفضاء

## النقل
مركبات الإطلاق ← الانتقال المداري ← الانتقال المحيط بالقمر ← الهبوط القمري ← الحركة السطحية ← الانتقال إلى المريخ ← الهبوط على المريخ.

## الطاقة
الدفع الكيميائي ← الطاقة الشمسية ← البطاريات ← المفاهيم التجديدية والانشطارية ← شبكات الطاقة السطحية.

## المعلومات
الشبكات الأرضية ← أقمار الترحيل ← الوصلات البصرية والراديوية ← الملاحة الذاتية ← أنظمة البيانات الموزعة.

## الاستقلالية
التوجيه والملاحة والتحكم ← اكتشاف الأخطار ← الهبوط الذاتي ← الروبوتات السطحية ← أنظمة مساعدة الطاقم ← التشغيل الذاتي للبنية التحتية.

## الموارد
توصيل المواد الاستهلاكية ← إعادة التدوير ← استخراج الماء والأكسجين محلياً ← المواد الأولية للبناء ← خدمات لوجستية تتجه تدريجياً إلى الحلقة المغلقة.

## التصنيع واسع النطاق
وتيرة الإطلاق ← التصنيع الكمي ← النقل القابل لإعادة الاستخدام ← التجميع المداري ← البنية التحتية السطحية القمرية ← استخدام الموارد ← الخدمات اللوجستية للفضاء العميق.

## أولوية البحث
يجب أن تُضاف لكل تقنية حقول كمية للكتلة والقدرة والإنتاجية وكفاءة الطاقة والعمر والنضج وسلسلة التبعيات وأدلة الاختبار ومتطلبات الواجهات.
