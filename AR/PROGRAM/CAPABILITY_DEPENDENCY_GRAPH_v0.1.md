# Cosmic Programm — الرسم البياني لتبعيات القدرات v0.1

## المستوى 0 — الأرض
الإطلاق التجاري ← تكامل المركبة الفضائية ← العمليات الأرضية.

## المستوى 1 — المدار
الطاقة ← الاتصالات ← الاستقلالية ← تشغيل الحمولة ← الاستعادة بعد الأعطال.

## المستوى 2 — الفضاء المحيط بالقمر
اتصالات الفضاء العميق ← الملاحة ← الإدارة الحرارية ← الاستقلالية طويلة المدة ← عمليات النقل.

## المستوى 3 — سطح القمر
الهبوط ← الطاقة ← الاتصالات ← البقاء الحراري ← الحركة على السطح ← استشعار الموارد.

## المستوى 4 — البنية التحتية
طاقة دائمة ← اتصالات دائمة ← واجهات موحدة معيارياً ← الخدمات اللوجستية ← معالجة الموارد.

## المستوى 5 — التمهيد الصناعي
استخراج الموارد ← التخزين ← المواد الاستهلاكية ← المواد الأولية للتصنيع ← الخدمات اللوجستية المتكررة.

## المستوى 6 — التمهيد للمريخ
الإقامة طويلة الأمد ← الطاقة السطحية ← الدخول والنزول والهبوط EDL ← استخدام الموارد المحلية ISRU ← الخدمات اللوجستية الذاتية ← أنظمة الطاقم.

## قاعدة التبعيات
لا تُعد القدرة ناضجة لمجرد أن نظاماً فرعياً يعمل منفرداً. وإنما تنضج عندما تُثبت واجهاتها وافتراضاتها البيئية وإجراءاتها التشغيلية واستعادتها بعد الأعطال ضمن نظام متكامل.
