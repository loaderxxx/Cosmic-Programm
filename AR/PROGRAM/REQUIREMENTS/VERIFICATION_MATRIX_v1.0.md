# مصفوفة التحقق v1.0

| المجال | طريقة التحقق | الدليل |
|---|---|---|
| الهيكل | تحليل + فحص + اختبارات تأهيل | الأحمال وهوامش المتانة وتقرير الاختبار |
| التحكم الحراري | تحليل + اختبار حراري في الفراغ | مطابقة النموذج الحراري للقياسات |
| الطاقة | تحليل + اختبار وظيفي | ميزانية التوليد والتخزين والأحمال |
| الاتصالات | تحليل + اختبار ترددات راديوية | الوصلة الراديوية ومعدل خطأ البتات BER ومعدل نقل البيانات |
| التحكم في الاتجاه | تحليل + اختبار العتاد ضمن الحلقة HIL / اختبار النظام | بيانات الدقة والاستقرار |
| الملاحة | محاكاة + اختبارات + طيران | ميزانية خطأ الملاحة |
| الاستقلالية | اختبارات برمجية + HIL + حقن أعطال | نتائج الاستعادة |
| واجهة الحمولة | فحص + اختبارات ميكانيكية وكهربائية | مطابقة وثيقة ضبط الواجهات ICD |
| البرمجيات | اختبارات الوحدات والتكامل والنظام | تغطية المتطلبات |
| القطاع الأرضي | عرض عملي شامل من البداية إلى النهاية | تدفق الأوامر والقياس عن بُعد والبيانات |
| التكامل مع مركبة الإطلاق | فحص الملاءمة + اختبار الواجهة | مطابقة ICD الخاصة بمركبة الإطلاق |
| التشغيل | محاكاة + تدريب تشغيلي | الإجراءات وسيناريوهات الطوارئ |
| الأداء في الطيران | قياس عن بُعد + تحليل ما بعد الطيران | الأداء المقاس مقارنة بالمحسوب |

يتطلب إغلاق المتطلب دليلاً موضوعياً يتوافق مع طريقة التحقق المختارة.
