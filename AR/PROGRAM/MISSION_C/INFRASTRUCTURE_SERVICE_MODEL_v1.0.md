# المهمة C — نموذج خدمات البنية التحتية v1.0

## الغرض

التعامل مع المهمة القمرية التمهيدية باعتبارها عقدة في بنية تحتية مستقبلية، لا مركبة منفردة.

## الخدمات

- الطاقة؛
- الاتصالات؛
- بيانات الملاحة؛
- الحوسبة؛
- استضافة الحمولة؛
- التشخيص؛
- التخزين المؤقت للبيانات؛
- الواجهة الميكانيكية؛
- التحضير للشحنة التالية.

## المقاييس

يُسجل لكل خدمة:
- التوافر؛
- القدرة الكهربائية؛
- معدل الإنجاز أو نقل البيانات؛
- التأخير؛
- العمر التشغيلي؛
- تحمل الأعطال؛
- تكلفة تقديم الخدمة؛
- قابلية التوسع.

## السؤال الأساسي

ما خصائص العقدة الأولى التي تجعل إضافة عقدة ثانية أسهل أو أقل تكلفة أو أكثر فائدة وظيفية؟

الحالة: مفاهيمية (CONCEPTUAL).
