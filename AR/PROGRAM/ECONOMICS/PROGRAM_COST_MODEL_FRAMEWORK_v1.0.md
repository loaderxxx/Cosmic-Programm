# إطار النموذج الاقتصادي للبرنامج v1.0

## الغرض

يجب أن يوضح النموذج الاقتصادي ليس سعر مهمة واحدة فقط، بل تكلفة اكتساب القدرة المتحقق منها التالية أيضاً.

## طبقات التكلفة

1. البحث؛
2. التصميم؛
3. إنشاء النماذج الأولية؛
4. التأهيل؛
5. الإنتاج؛
6. التكامل؛
7. الإطلاق؛
8. الاتصالات والقطاع الأرضي؛
9. التشغيل؛
10. تحليل البيانات؛
11. الصيانة؛
12. إعادة الاستخدام؛
13. الإخراج من الخدمة.

## المقاييس الرئيسية

- تكلفة المهمة؛
- تكلفة كل كيلوغرام من المعدات المنقولة؛
- تكلفة ساعة التشغيل؛
- تكلفة وحدة البيانات المفيدة؛
- تكلفة القدرة المتحقق منها؛
- تكلفة التكرار؛
- تكلفة الإخفاق؛
- تكلفة تغيير التصميم.

## التوسع

تُنمذج بصورة منفصلة:
**مهمة إثبات واحدة ← سلسلة صغيرة ← سلسلة قابلة للتكرار ← منظومة بنية تحتية.**

المعامل الأساسي ليس أدنى سعر أولي، بل تغير التكلفة والمخاطر عند التكرار.

الحالة: إطار عمل (FRAMEWORK).
