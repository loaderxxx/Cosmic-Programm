# إطار التوافق والتداخل الكهرومغناطيسي EMC/EMI v1.0

## الغرض

منع حالة تجتاز فيها الأنظمة الفرعية الاختبارات منفردة، ثم تصبح غير متوافقة بعد التكامل.

## مصادر التداخل

- المرسلات؛
- إلكترونيات القدرة؛
- محولات DC/DC؛
- المحركات وآليات التشغيل؛
- الحواسيب الرقمية؛
- مولدات إشارات الساعة؛
- شبكات الكابلات؛
- المصادر الخارجية.

## العناصر المعرضة للتأثر

- المستشعرات؛
- المستقبلات؛
- الوصلات عالية السرعة؛
- دوائر القياس التناظرية؛
- أنظمة التوقيت؛
- ADCS؛
- الذاكرة.

## الضبط

يُسجل:
- مستويات الانبعاث؛
- القابلية للتأثر؛
- التداخل المنقول بالتوصيل؛
- التداخل المشع؛
- التأريض؛
- التدريع؛
- الترشيح؛
- مسارات الكابلات؛
- التوافق بين أوضاع التشغيل.

## التحقق

يُجرى التحليل في المراحل المبكرة، ثم اختبارات EMC/EMI على مستوى الأنظمة الفرعية والنظام المتكامل.

الحالة: إطار عمل (FRAMEWORK).
