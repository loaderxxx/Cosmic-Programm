# إطار تحديد الاتجاه والتحكم فيه ADCS والملاحة v1.0

## الغرض

إطار هندسي علني لاختيار نظام تحديد الاتجاه والتحكم فيه والملاحة والتحقق منه.

## السلسلة الوظيفية

**تحديد الحالة ← تقدير الحالة ← تخطيط الاتجاه ← التحكم ← المشغلات ← قياس النتيجة ← اكتشاف الخطأ ← الوضع الآمن.**

## المستشعرات

تُدرس الخيارات التالية:
- مستشعرات الشمس؛
- الجيروسكوبات؛
- مقاييس التسارع؛
- مقاييس المجال المغناطيسي لتطبيقات المدار المنخفض؛
- متتبعات النجوم؛
- الملاحة بالأقمار الصناعية GNSS حيث تتاح؛
- الملاحة الراديوية؛
- الطرق البصرية والليدار للأوضاع المتخصصة.

يُسجل لكل مستشعر: الدقة ومعدل التحديث والتأخير وأنماط الإخفاق والاعتماد على درجة الحرارة وشروط التطبيق.

## المشغلات

تُدرس الخيارات التالية:
- عجلات رد الفعل؛
- المشغلات المغناطيسية؛
- الدافعات الصغيرة؛
- آليات التشغيل المتخصصة.

يُسجل لكل منها نطاق العزم والتشبع والاستهلاك والعمر التشغيلي والاهتزازات وحالات الإخفاق.

## الأوضاع

يجب التحقق، كحد أدنى، من:
1. التهيئة الأولية؛
2. تحقيق الاستقرار؛
3. التوجيه نحو الأرض؛
4. التوجيه نحو الشمس؛
5. ضبط الاتجاه عالي الدقة؛
6. المناورة؛
7. فقدان مستشعر؛
8. فقدان مشغل؛
9. الوضع الآمن؛
10. الاستعادة.

## الملاحة

يُحدد لكل مهمة:
- الحالة المطلقة؛
- الحالة النسبية؛
- مصدر الزمن؛
- الإطار الإحداثي؛
- التحويلات بين الأطر؛
- خطأ الموقع المسموح؛
- خطأ السرعة المسموح؛
- خطأ الاتجاه المسموح؛
- التأخيرات المسموحة.

## التحقق

تلزم المحاكاة واختبارات البرمجيات ضمن الحلقة والعتاد ضمن الحلقة واختبارات عتاد مماثل للطيران حيث تدعو الحاجة.

الحالة: إطار عمل (FRAMEWORK).
