# إطار الموثوقية واكتشاف الأعطال وعزلها والاستعادة منها FDIR v1.0

## الغرض

FDIR: اكتشاف العطل وعزله والاستعادة منه.

## السلسلة

**الملاحظة ← اكتشاف الحالة غير الطبيعية ← التصنيف ← العزل ← الانتقال إلى حالة آمنة ← الاستعادة ← تأكيد النتيجة.**

## فئات الإخفاق

- المستشعر؛
- المشغل؛
- الطاقة؛
- الحاسوب؛
- الذاكرة؛
- الاتصالات؛
- ارتفاع الحرارة؛
- حدث إشعاعي؛
- خطأ برمجي؛
- تدهور ميكانيكي.

## لكل عطل

يُسجل:
- العَرَض؛
- مصدر البيانات؛
- زمن الاكتشاف؛
- ظروف الإنذارات الإيجابية الكاذبة؛
- زمن الاستجابة المسموح؛
- إجراء FDIR؛
- الوظائف المتبقية؛
- طريقة الاستعادة.

## الحالات الآمنة

يجب أن يحدد الوضع الآمن صراحة:
- استهلاك الطاقة؛
- الاتجاه؛
- الاتصالات؛
- الحد الأدنى من الأنظمة الفعالة؛
- شروط الخروج؛
- القيود على الإجراءات الذاتية.

## التحقق

يجب إعادة إنتاج كل سيناريو حرج في نموذج أو على منصة اختبار، وفي النظام المتكامل متى أمكن.

الحالة: إطار عمل (FRAMEWORK).
