# إطار وثيقة ضبط الواجهات ICD لـCosmic Programm v1.0

## الغرض

تحدد وثيقة ICD الحدود بين الأنظمة الفرعية وتمنع الافتراضات الخفية المتعلقة بالواجهات.

## فئات الواجهات

### الميكانيكا
- المثبتات؛
- الأبعاد؛
- الكتلة؛
- مركز الكتلة؛
- الأحمال؛
- الاهتزازات؛
- النشر.

### الكهرباء
- الجهد؛
- التيار؛
- تيارات البدء؛
- القيم القصوى؛
- التأريض؛
- الحماية؛
- EMC/EMI.

### البيانات
- الواجهة الفيزيائية؛
- البروتوكول؛
- معدل النقل؛
- التأخير؛
- التنسيق؛
- فحص السلامة والتكامل؛
- المرجع الزمني.

### الحرارة
- واجهات التوصيل الحراري؛
- التدفقات الحرارية؛
- درجات الحرارة المسموحة؛
- المشعات؛
- العزل.

### الترددات الراديوية
- نطاق التردد؛
- القدرة؛
- عرض النطاق؛
- التضمين؛
- الهوائي؛
- قيود التوافق.

## قاعدة الواجهة

يجب أن يكون لكل واجهة مسؤول في كل طرف، وبيان توافق قابل للتحقق.

صيغة السجل:

**ID ← مصدر المتطلب ← الطرف A ← الطرف B ← المعامل ← النطاق المسموح ← طريقة التحقق ← الحالة.**

الحالة: إطار عمل (FRAMEWORK).
