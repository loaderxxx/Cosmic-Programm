# إطار ميزانية الوصلة الراديوية v1.0

## الغرض
قالب موحد لحسابات اتصالات مهمات Cosmic Programm. تُملأ المعاملات المحددة بعد اختيار نطاق التردد والمدار والهوائيات والقطاع الأرضي.

## المعادلة الأساسية
<div dir="ltr">

Pr = Pt + Gt + Gr − Lspace − Latm − Lpol − Lpoint − Lother

</div>

حيث Pt قدرة المرسل؛ وGt/Gr كسب الهوائيات؛ وLspace خسارة الفضاء الحر؛ وLatm الخسارة الجوية؛ وLpol خسارة الاستقطاب؛ وLpoint خسارة التوجيه؛ وLother الخسائر الأخرى.

## القطاع الفضائي
- المدار والارتفاع؛
- نطاق التردد؛
- قدرة المرسل؛
- كسب الهوائي ومخططه؛
- أخطاء التوجيه؛
- الترميز والتضمين؛
- معدل البيانات المطلوب؛
- نسبة زمن التشغيل duty cycle؛
- قيود الطاقة.

## القطاع الأرضي
- نوع الهوائي ومعاملاته؛
- الكسب؛
- حساسية المستقبل؛
- درجة حرارة الضوضاء؛
- توافر المحطات؛
- مدة نوافذ الاتصال؛
- القيود الهندسية والجوية.

## قناة البيانات
يُفصل بين الأوامر والقياس الهندسي عن بُعد والأحداث الحرجة وبيانات الحمولة المفيدة والبيانات الخدمية وإعادة الإرسال.

## الحساسية
تُحلل بصورة منفصلة آثار تراجع دقة التوجيه وانخفاض القدرة وزيادة الخسائر وتقلص نافذة الاتصال وأخطاء التنبؤ وتدهور المعدات.

## مخرجات الحساب
الهندسة المكانية ← معاملات المرسل ← معاملات الهوائيات ← الخسائر ← Eb/N0 أو SNR ← معدل البيانات ← BER/FER ← الهامش ← التوافر ← القيود.

الحالة: إطار عمل (FRAMEWORK)؛ تتطلب القيم المحددة حساباً خاصاً بالمهمة.
