# سجل مخاطر البرنامج والهندسة v1.0

## الفئات الرئيسية
| الفئة | الخطر | ما يجب التحقق منه |
|---|---|---|
| R1 | معاملات إدخال غير صحيحة | المصدر الأولي والتاريخ والوحدات والنطاق |
| R2 | طاقة غير كافية | القدرة المتوسطة والقصوى والتخزين والكسوف والهامش |
| R3 | وصلة اتصالات غير كافية | ميزانية الوصلة والنوافذ والتوجيه والخسائر |
| R4 | خطأ الملاحة أو الاتجاه | ADCS والمستشعرات والمشغلات |
| R5 | إخفاق النظام الحاسوبي | مؤقت المراقبة والتكرار الاحتياطي والوضع الآمن |
| R6 | عدم توافق حراري | أسوأ حالات السخونة والبرودة والحالات الانتقالية |
| R7 | البيئة الإشعاعية | الجرعة وتأثيرات الحدث المنفرد والتدريع |
| R8 | عدم توافق الواجهات | الميكانيكا والطاقة والبيانات وEMC/EMI |
| R9 | تحقق غير كافٍ | تغطية الاختبارات والمستوى الصحيح للاختبار |
| R10 | الاعتماد على مورد | التوافر والواجهة والجدول والاستبدال |
| R11 | استقلالية غير متحقق منها | HIL وبيئة مماثلة للطيران وسيناريوهات الأعطال |
| R12 | خطأ التوسع | الانتقال إلى نظام متكرر دون بيانات مؤكدة |

## قاعدة الأدلة
يجب أن يتضمن كل خطر مهم: شرط الحدوث ← الأثر الملحوظ ← الاكتشاف ← الحد من الخطر ← التحقق ← عدم اليقين المتبقي.

## المبدأ المحوري
نجاح الإطلاق وحده لا يثبت الهندسة. الدليل هو مجموعة نتائج مقاسة تتيح نقل قدرة مؤكدة إلى المهمة التالية.

الحالة: خط أساس (BASELINE)؛ ويُجرى الترتيب الكمي بعد الحصول على بيانات خاصة بالمهمة.
