# مصفوفة الموردين والواجهات v1.0

## الغرض

تحديد العناصر التي يُستحسن الحصول عليها خارجياً والعناصر التي يجب أن تبقى تحت سيطرة الهندسة.

## الفئات

| الفئة | نوع القرار |
|---|---|
| مركبة الإطلاق | الشراء غالباً |
| الإطلاق المشترك القياسي | الشراء |
| خدمات الاتصال الأرضية | الشراء / الشراكة |
| المكونات الإلكترونية القياسية | الشراء |
| الحمولة الفريدة | التطوير / الامتلاك |
| هندسة المهمة | التطوير / الامتلاك |
| البرمجيات الذاتية | التطوير / الامتلاك |
| نظام البيانات | التطوير / الامتلاك |
| الواجهات المتخصصة | التطوير / الامتلاك / الشراكة |
| البنية التحتية القمرية | نموذج مختلط |

## لكل مورد

يُسجل:
- المنتج؛
- الواجهة؛
- النضج؛
- التوافر؛
- القيود؛
- قابلية الاستبدال؛
- القيود التصديرية والقانونية؛
- مهلة التسليم؛
- اعتماد البرنامج عليه؛
- خطة الاستبدال.

## القاعدة

يجب ألا يصبح مكوّن خارجي نقطة إخفاق وحيدة خفية في الهندسة.

الحالة: إطار عمل (FRAMEWORK).
