# الرسم البياني لتبعيات مهمات Cosmic Programm v1.0

## السلسلة الأساسية

المعرفة والمتطلبات ← مهمة إثبات مدارية ← استقلالية واتصالات وطاقة متحقق منها ← استكشاف موارد القمر ← بيانات بيئية موثقة ← مهمة إثبات للبنية التحتية ← خدمات لوجستية متكررة ← معالجة الموارد ← بنية تحتية دائمة ← مهمات تمهيدية للمريخ.

## التبعيات الحرجة

### مهمة الإثبات المدارية
تعتمد على:
- اختيار مركبة الإطلاق؛
- واجهة الحمولة؛
- ميزانية الكتلة؛
- ميزانية الطاقة؛
- الوصلة الراديوية؛
- القطاع الأرضي؛
- خطة التأهيل.

### المستكشف القمري
يعتمد، إضافة إلى ذلك، على:
- الملاحة؛
- النموذج الحراري؛
- نموذج الإشعاع؛
- الاتصالات القمرية؛
- حل الهبوط والنقل.

### مهمة إثبات البنية التحتية
تعتمد، إضافة إلى ذلك، على:
- بيئة جرى التحقق منها؛
- طاقة طويلة الأمد؛
- الحماية من الغبار؛
- موثوقية الاتصالات؛
- الإدارة الذاتية للحالة الصحية للنظام.

## القاعدة

لا يجوز الانتقال إلى المرحلة التالية لمجرد نجاح إطلاق المركبة السابقة. فالانتقال يتطلب إغلاق تبعيات تقنية محددة والحصول على البيانات التي أُنشئت المرحلة من أجلها.
