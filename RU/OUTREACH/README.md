# Внешние исследования и взаимодействие

## Миссия

Соединять Cosmic Programm с серьёзными исследователями, инженерами, предпринимателями, организациями и разработчиками, работающими над сложными или нестандартными задачами.

## Целевые категории

- космические агентства
- исследователи перспективной тяги
- команды робототехники и автономности
- исследователи космических ресурсов
- компании в области запусков и инфраструктуры
- исследователи ИИ и космоса
- университеты
- исследователи радикальных концепций
- инвесторы в долгосрочные технологии

## Пакет для внешнего контакта

Перед контактом подготовить:
1. одностраничное описание миссии
2. архитектуру
3. наиболее сильные доказательства
4. явные гипотезы
5. ключевые неизвестные
6. конкретный вопрос
7. предложение по сотрудничеству
8. границу проприетарной информации

Внешнее взаимодействие не должно подразумевать несуществующее одобрение, финансирование, партнёрство или личный доступ.
