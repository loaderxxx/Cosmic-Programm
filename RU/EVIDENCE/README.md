# Интерфейс доказательств

Этот публичный каталог содержит только очищенные и публичные доказательства.

Для каждого важного утверждения хранить:
- утверждение
- источник
- дату
- тип источника
- релевантный показатель
- интерпретацию
- уровень уверенности
- ограничения
- условие опровержения
- дату последней проверки

## Иерархия источников

1. первичные документы государственных органов и агентств
2. рецензируемые научные исследования
3. технические стандарты
4. технические отчёты институтов
5. качественная техническая документация отрасли
6. вторичный анализ
7. обсуждения сообщества

Цитата подтверждает существование источника; она автоматически не доказывает правильность нашей интерпретации.
