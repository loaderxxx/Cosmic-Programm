## 11. Граница PUBLIC / PRIVATE CORE

Публичный репозиторий содержит технические факты, исследования, результаты, архитектуры, требования, испытания и опубликованные выводы.

Внутренние алгоритмы, закрытые промпты, детальная методология принятия решений и другие защищённые элементы находятся в Private Core и в этот индекс не включаются.

## 12. Как читать программу

**Сначала:** Манифест → Архитектура → Дорожная карта.

**Затем:** Граф зависимостей → Матрица возможностей → Системные требования.

**Затем:** инженерные базы → внешние baseline → бюджеты → верификация → риски.

**После этого:** миссии A/B/C и их экспериментальные результаты.

Главный принцип: каждое новое утверждение должно иметь происхождение, уровень доказательности и понятный путь к верификации.
