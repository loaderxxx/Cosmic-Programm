# Карта технологических пробелов Cosmic Programm v1.0

## Класс A — неизвестность миссии

- окончательная орбита первой миссии;
- точная полезная нагрузка;
- требуемая продолжительность;
- требования к связи;
- радиационная среда;
- тепловая среда.

## Класс B — инженерная зрелость

- автономное управление отказами;
- компактная энергетическая система;
- надёжная связь;
- высокоточная ориентация;
- автономная навигация;
- термовакуумная квалификация;
- интеграция ПО и аппаратуры.

## Класс C — лунные технологии

- посадочная навигация;
- работа в пылевой среде;
- поверхностная энергетика;
- долговременное хранение энергии;
- поверхностная связь;
- автономная мобильность;
- ресурсная разведка.

## Класс D — масштабирование

- повторяемое производство;
- стандартизированные интерфейсы;
- квалификация серийных аппаратов;
- запасные элементы;
- запуск нескольких миссий;
- совместимость оборудования разных поколений.

## Правило приоритета

Пробел получает высокий приоритет не из-за своей сложности, а если он:
1. блокирует следующую миссию;
2. имеет высокий риск;
3. требует длительного времени на проверку;
4. создаёт данные, полезные для многих будущих миссий.
