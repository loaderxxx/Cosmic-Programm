# Сводная база времени, данных и происхождения v1.0

## Назначение

Создать единый принцип происхождения технических данных программы.

## Минимальная запись измерения

- идентификатор;
- время;
- временная шкала;
- источник;
- аппарат;
- подсистема;
- датчик;
- конфигурация;
- единицы;
- сырое значение;
- обработанное значение;
- алгоритм обработки;
- версия ПО;
- качество;
- неопределённость.

## Происхождение

Каждый опубликованный технический вывод должен позволять пройти цепочку:

**источник → извлечение → нормализация → расчёт/обработка → результат → документ программы.**

## Версии

Изменение исходного параметра не должно молча менять старый вывод. Старый результат сохраняется с указанием версии и причины изменения.

## Принцип

Данные без происхождения не становятся инженерным фактом только потому, что выглядят правдоподобно.

Статус: BASELINE.
