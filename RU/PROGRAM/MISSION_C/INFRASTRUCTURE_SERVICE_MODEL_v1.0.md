# Миссия C — модель инфраструктурного сервиса v1.0

## Назначение

Рассматривать лунный pathfinder как узел будущей инфраструктуры, а не изолированный аппарат.

## Сервисы

- энергия;
- связь;
- навигационные данные;
- вычисления;
- размещение полезной нагрузки;
- диагностика;
- временное хранение данных;
- механический интерфейс;
- подготовка следующего груза.

## Метрики

Для каждого сервиса фиксировать:
- доступность;
- мощность;
- пропускную способность;
- задержку;
- ресурс;
- отказоустойчивость;
- стоимость предоставления;
- возможность масштабирования.

## Главный вопрос

Какие характеристики одного узла делают добавление второго узла проще, дешевле или функционально полезнее?

Статус: CONCEPTUAL.
