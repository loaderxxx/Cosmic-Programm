# Миссия C — CONOPS v1.0

## Назначение

Лунный инфраструктурный pathfinder проверяет длительную работу модульного узла: энергия, связь, навигация, вычисления, автономность и полезная нагрузка.

## Фазы

1. доставка;
2. посадка/развёртывание;
3. ввод в эксплуатацию;
4. проверка энергосистемы;
5. проверка связи;
6. автономная работа;
7. работа полезных нагрузок;
8. переходы hot/cold;
9. отказовые сценарии;
10. обслуживание/переконфигурация;
11. подготовка к следующему грузу.

## Основной результат

Создать измеренную базу для повторной доставки и наращивания инфраструктуры.

## Ключевой принцип

Миссия C должна проектироваться не как одиночный эксперимент, а как первый элемент повторяемой цепочки.

Статус: CONCEPTUAL.
