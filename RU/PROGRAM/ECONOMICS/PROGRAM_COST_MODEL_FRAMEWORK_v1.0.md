# Каркас экономической модели программы v1.0

## Назначение

Экономическая модель должна показывать не только цену одной миссии, но и стоимость накопления следующей проверенной возможности.

## Слои затрат

1. исследование;
2. проектирование;
3. прототипирование;
4. квалификация;
5. производство;
6. интеграция;
7. запуск;
8. связь и наземный сегмент;
9. эксплуатация;
10. анализ данных;
11. обслуживание;
12. повторное использование;
13. вывод из эксплуатации.

## Основные метрики

- стоимость миссии;
- стоимость килограмма доставленного оборудования;
- стоимость часа эксплуатации;
- стоимость единицы полезных данных;
- стоимость проверенной возможности;
- стоимость повторения;
- стоимость отказа;
- стоимость изменения конструкции.

## Масштабирование

Отдельно моделировать:
**единичный демонстратор → малая серия → повторяемая серия → инфраструктурная система.**

Ключевой параметр — не минимальная первоначальная цена, а изменение стоимости и риска при повторении.

Статус: FRAMEWORK.
