# Миссия B — модель ресурсных данных v1.0

## Назначение

Определить, какие данные необходимы для перехода от общего предположения о ресурсе к инженерно полезному решению.

## Иерархия

1. наличие;
2. пространственное распределение;
3. глубина;
4. концентрация;
5. физическое состояние;
6. доступность;
7. изменчивость;
8. объём доступного ресурса;
9. неопределённость измерения;
10. пригодность для последующего процесса.

## Измерения

Для каждого измерения фиксировать:
- координаты;
- время;
- метод;
- разрешение;
- точность;
- условия среды;
- повторяемость;
- происхождение данных.

## Решение

Нельзя переходить к проектированию добычи только на основании обнаружения сигнала. Нужна оценка инженерной доступности ресурса.

Статус: FRAMEWORK.
