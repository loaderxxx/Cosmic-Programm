# Каркас ICD Cosmic Programm v1.0

## Назначение

ICD фиксирует границы между подсистемами и не допускает скрытых интерфейсных допущений.

## Категории интерфейсов

### Механика
- крепёж;
- габариты;
- масса;
- центр масс;
- нагрузки;
- вибрации;
- развёртывание.

### Электрика
- напряжение;
- ток;
- пусковые токи;
- пики;
- заземление;
- защита;
- EMC/EMI.

### Данные
- физический интерфейс;
- протокол;
- скорость;
- задержка;
- формат;
- контроль целостности;
- временная база.

### Тепло
- проводящие интерфейсы;
- тепловые потоки;
- допустимые температуры;
- радиаторы;
- изоляция.

### Радиочастота
- диапазон;
- мощность;
- полоса;
- модуляция;
- антенна;
- ограничения совместимости.

## Правило интерфейса

Каждый интерфейс должен иметь владельца с обеих сторон и проверяемое утверждение совместимости.

Формат записи:

**ID → источник требования → сторона A → сторона B → параметр → допустимый диапазон → метод проверки → статус.**

Статус: FRAMEWORK.
