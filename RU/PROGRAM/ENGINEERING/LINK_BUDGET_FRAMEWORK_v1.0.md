# Каркас бюджета радиолинии v1.0

## Назначение
Единый шаблон расчёта связи миссий Cosmic Programm. Конкретные параметры заполняются после выбора диапазона, орбиты, антенн и наземного сегмента.

## Основное уравнение
Pr = Pt + Gt + Gr − Lspace − Latm − Lpol − Lpoint − Lother

где Pt — мощность передатчика; Gt/Gr — усиления антенн; Lspace — потери в свободном пространстве; Latm — атмосферные потери; Lpol — потери поляризации; Lpoint — потери наведения; Lother — прочие потери.

## Космический сегмент
- орбита и высота;
- диапазон частот;
- мощность передатчика;
- усиление и диаграмма антенны;
- ошибки наведения;
- кодирование и модуляция;
- требуемая скорость;
- duty cycle;
- ограничения питания.

## Наземный сегмент
- тип и параметры антенны;
- усиление;
- чувствительность приёмника;
- шумовая температура;
- доступность станций;
- длительность окон;
- геометрические и погодные ограничения.

## Канал данных
Разделять командный канал, инженерную телеметрию, критические события, полезные данные, служебные данные и повторную передачу.

## Чувствительность
Отдельно анализировать ухудшение наведения, снижение мощности, рост потерь, сокращение окна связи, ошибки прогнозирования и деградацию оборудования.

## Выход расчёта
Геометрия → параметры передатчика → параметры антенн → потери → Eb/N0 или SNR → скорость → BER/FER → запас → доступность → ограничения.

Статус: FRAMEWORK / конкретные значения требуют mission-specific расчёта.
