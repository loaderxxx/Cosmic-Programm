# Каркас ADCS и навигации v1.0

## Назначение

Публичная инженерная рамка для выбора и проверки системы определения и управления ориентацией и навигацией.

## Функциональная цепочка

**Определение состояния → оценка состояния → планирование ориентации → управление → исполнительные органы → измерение результата → обнаружение ошибки → безопасный режим.**

## Датчики

Рассматривать:
- солнечные датчики;
- гироскопы;
- акселерометры;
- магнитометры для низкоорбитальных применений;
- звёздные датчики;
- GNSS там, где доступно;
- навигацию по радиоканалу;
- оптические/лидарные методы для специализированных режимов.

Для каждого датчика фиксировать точность, частоту обновления, задержку, отказовые режимы, температурную зависимость и условия применимости.

## Исполнительные органы

Рассматривать:
- реакционные колёса;
- магнитные исполнительные органы;
- двигательные микродвигатели;
- специализированные приводы.

Для каждого: диапазон момента, насыщение, потребление, ресурс, вибрации и отказовые состояния.

## Режимы

Минимально проверить:
1. инициализация;
2. стабилизация;
3. наведение на Землю;
4. наведение на Солнце;
5. высокоточная ориентация;
6. манёвр;
7. потеря датчика;
8. потеря исполнительного органа;
9. безопасный режим;
10. восстановление.

## Навигация

Для каждой миссии определить:
- абсолютное состояние;
- относительное состояние;
- источник времени;
- система координат;
- преобразования между системами;
- допустимую ошибку положения;
- допустимую ошибку скорости;
- допустимую ошибку ориентации;
- допустимые задержки.

## Верификация

Требуются моделирование, software-in-the-loop, hardware-in-the-loop и испытания flight-like аппаратуры там, где это необходимо.

Статус: FRAMEWORK.
