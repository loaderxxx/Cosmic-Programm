# Cosmic Programm — граф зависимостей возможностей v0.1

## Уровень 0 — Земля
Коммерческий запуск → интеграция космического аппарата → наземная эксплуатация.

## Уровень 1 — Орбита
Энергия → связь → автономность → работа полезной нагрузки → восстановление после отказов.

## Уровень 2 — Окололунное пространство
Дальняя космическая связь → навигация → тепловое управление → длительная автономность → транспортные операции.

## Уровень 3 — Поверхность Луны
Посадка → энергия → связь → тепловое выживание → поверхностная мобильность → измерение ресурсов.

## Уровень 4 — Инфраструктура
Постоянная энергетика → постоянная связь → стандартизованные интерфейсы → логистика → переработка ресурсов.

## Уровень 5 — Промышленный предшественник
Добыча ресурсов → хранение → расходные материалы → производственное сырьё → повторяемая логистика.

## Уровень 6 — Марсианский предшественник
Длительное обитание → поверхностная энергетика → вход в атмосферу, снижение и посадка (EDL) → ISRU → автономная логистика → системы экипажа.

## Правило зависимостей
Возможность не считается зрелой только потому, что подсистема работает отдельно. Зрелость возникает, когда в интегрированной системе продемонстрированы интерфейсы, предположения о среде, эксплуатационные процедуры и восстановление после отказов.
