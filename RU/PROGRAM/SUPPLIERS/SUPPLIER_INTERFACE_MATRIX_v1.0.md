# Матрица поставщиков и интерфейсов v1.0

## Назначение

Определить, какие элементы целесообразно получать извне, а какие должны оставаться под контролем архитектуры.

## Категории

| Категория | Тип решения |
|---|---|
| Ракета-носитель | преимущественно BUY |
| Стандартный rideshare | BUY |
| Наземные услуги связи | BUY/PARTNER |
| Стандартные электронные компоненты | BUY |
| Уникальная полезная нагрузка | BUILD/OWN |
| Миссионная архитектура | BUILD/OWN |
| Автономное ПО | BUILD/OWN |
| Система данных | BUILD/OWN |
| Специализированные интерфейсы | BUILD/OWN/PARTNER |
| Лунная инфраструктура | смешанная модель |

## Для каждого поставщика

Фиксировать:
- продукт;
- интерфейс;
- зрелость;
- доступность;
- ограничения;
- заменяемость;
- экспортные/правовые ограничения;
- срок поставки;
- зависимость программы;
- план замены.

## Правило

Внешний компонент не должен превращаться в скрытую единственную точку отказа архитектуры.

Статус: FRAMEWORK.
