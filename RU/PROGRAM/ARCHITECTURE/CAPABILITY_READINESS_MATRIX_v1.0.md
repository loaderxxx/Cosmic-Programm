# Матрица готовности возможностей v1.0

## Назначение

Связать архитектуру программы с фактической доказанностью возможностей.

## Уровни

**L0 — идея:** функция описана.

**L1 — анализ:** физическая реализуемость поддержана расчётом.

**L2 — лаборатория:** функция показана в контролируемых условиях.

**L3 — интеграция:** функция работает совместно с другими подсистемами.

**L4 — flight-like:** функция проверена в условиях, близких к эксплуатации.

**L5 — космическая демонстрация:** функция подтверждена в реальном космосе.

**L6 — повторяемая эксплуатация:** функция подтверждена более чем одной эксплуатационной реализацией.

## Применение

Для каждой возможности фиксировать:
- текущий уровень;
- доказательство;
- неизвестность;
- следующий эксперимент;
- зависимые миссии;
- условия повышения уровня.

## Правило

Уровень готовности возможности не должен выводиться только из зрелости отдельного компонента. Важна готовность функции в контексте системы.

Статус: BASELINE.
