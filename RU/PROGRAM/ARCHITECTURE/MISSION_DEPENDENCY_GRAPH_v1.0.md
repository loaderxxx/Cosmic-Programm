# Граф зависимостей миссий Cosmic Programm v1.0

## Базовая цепочка

Знания и требования
→ орбитальный демонстратор
→ проверенные автономность/связь/энергетика
→ лунная ресурсная разведка
→ подтверждённые данные среды
→ инфраструктурный демонстратор
→ повторяемая логистика
→ ресурсная переработка
→ постоянная инфраструктура
→ марсианские предшественники.

## Критические зависимости

### Орбитальный демонстратор
Зависит от:
- выбора носителя;
- интерфейса полезной нагрузки;
- бюджета массы;
- энергетического бюджета;
- радиолинии;
- наземного сегмента;
- плана квалификации.

### Лунный разведчик
Дополнительно зависит от:
- навигации;
- тепловой модели;
- радиационной модели;
- лунной связи;
- посадочного/транспортного решения.

### Инфраструктурный демонстратор
Дополнительно зависит от:
- подтверждённой среды;
- долговременной энергетики;
- защиты от пыли;
- надёжности связи;
- автономного управления состоянием.

## Правило

Нельзя переходить к следующему этапу только потому, что предыдущий аппарат успешно запущен. Переход требует закрытия конкретных технических зависимостей и получения данных, ради которых этап был создан.
