# План сквозной верификации и валидации v1.0

## Цель

Связать требования программы с испытаниями, моделированием и эксплуатационными данными.

## Уровни

### Анализ
Проверка расчётами, моделями и инженерными оценками.

### Проверка компонентов
Функциональные и параметрические испытания отдельных компонентов.

### Подсистема
Проверка взаимодействия компонентов.

### Система
Проверка полного аппарата.

### Сквозная система
Аппарат + наземный сегмент + каналы связи + программное обеспечение + сценарий операции.

### Эксплуатация
Проверка фактическим полётным результатом.

## Для каждого требования

Фиксировать:

**REQ-ID → метод V&V → оборудование/модель → входные условия → процедура → измерение → критерий → результат → доказательство → статус.**

## Типы методов

- INSPECTION;
- ANALYSIS;
- TEST;
- DEMONSTRATION;
- FLIGHT DATA.

## Правило

Нельзя закрывать требование только ссылкой на похожую систему другой организации. Внешняя система может быть источником baseline, но соответствие Cosmic Programm требует собственной проверки применимости.

Статус: BASELINE.
