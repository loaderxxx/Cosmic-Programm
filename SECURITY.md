# Security & Public/Private Boundary

This repository is intentionally public.

## Never publish

- credentials
- API keys
- private contact data
- private system prompts
- protected AI orchestration
- private infrastructure
- protected algorithms
- Evidence Vault material
- confidential partner information
- unpublished invention details where disclosure could create IP risk

## Sanitization

CLASSIFY → REDACT → IP REVIEW → PRIVACY REVIEW → SECURITY REVIEW → PUBLISH

## IP

Potentially valuable inventions must be evaluated before public disclosure.

Classification:
- patent candidate
- trade secret
- copyright/software
- know-how
- open publication
- monitor

## Human control

External commitments, legal agreements, financial commitments and irreversible disclosures require human authorization.

## Recovery

The private canonical system should maintain protected backups independent of this public repository.

Public documentation is not a substitute for legal, security or engineering review.
