## Общие исходные записи

[CATALOG_SOURCE.json](CATALOG_SOURCE.json) — неизменённый публичный отраслевой каталог из commit `75066d88bbcc96eb63f6242df48cbcf5eac9fc67`. [portal.json](portal.json) фиксирует исходную базу, языковые ветки и читательские страницы. Эти файлы — общие метаданные доказательной базы, а не независимая проверка заявлений компаний.

**Правило путей:** значения `path` в сохранённом каталоге отсчитываются от ИСХОДНОГО корня, а не от папки DATA. Разрешайте их относительно `industry_source_root` в portal.json. Например, P001 соответствует `ORGANIZATIONS/P001_antaris-inc/README.md` внутри исходного корня. Мы не переписываем исходные записи незаметно и не объединяем старую исследовательскую ветку целиком.

## Оценки источников в срезе из 55 записей

| Класс | Число | Значение |
|---|---:|---|
| PRODUCT_PRIMARY_SOURCE | 40 | Есть первичная продуктовая/организационная ссылка; характеристики не сертифицированы независимо. |
| EVENT_PROFILE_ONLY | 4 | Только выставочные/профильные сведения; исследование продукта не завершено. |
| PRELIMINARY_SOURCE | 2 | Предварительный источник, требующий дальнейшей проверки. |
| ORGANIZATION_INFO | 1 | Сведения об организации, а не квалификация продукта. |
| IDENTITY_UNKNOWN | 8 | Идентичность не установлена; запись не является проверенным поставщиком. |

Категории описывают исходный срез. Посещение выставки и отношения с COSMOSYNTH — отдельные характеристики, их нельзя выводить из продуктовой ссылки.

## Одна цепочка доказательств

Используйте устойчивые ID организаций и исследований, язык оригинала, URL, даты публикации и проверки, область, класс утверждения, неопределённость и точные версии. Дополнительные RU/AR-источники согласуются с английской записью. Перевод сохраняет числа, единицы, даты, ID источников, оговорки и различие между предложениями и результатами.

Подробные отраслевые досье пока остаются английскими оригиналами. Новый вход и пояснения каталога доступны на трёх языках; [охват перевода](../../RESEARCH_STATUS.md) указан прямо. Приватные контакты, история отношений и внутренние приоритеты в эти публичные наборы не входят.
