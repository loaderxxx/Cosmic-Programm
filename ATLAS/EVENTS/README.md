# الفعاليات مصادر وليست هيكل المعرفة

[الأطلس](../README.md) · [English](https://github.com/loaderxxx/Cosmic-Programm/blob/main/ATLAS/EVENTS/README.md) · [Русский](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ru/ATLAS/EVENTS/README.md) · [العربية](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ar/ATLAS/EVENTS/README.md)

نشأت مجموعة البحث الصناعي الأولية من دراسة CABSAT / SATExpo Dubai 2026. يحتفظ الدليل الأصلي بـ51 سجلاً مرتبطاً بـSATExpo أو مذكوراً في سياقه، وأربعة سجلات متقاطعة مع CABSAT. إنها عينة بحثية جزئية، لا تعداد رسمي كامل للعارضين ولا سجل لقاءات مع COSMOSYNTH.

قد تساعد الفعالية في اكتشاف شركة، لكنها لا تثبت هويتها القانونية أو قدرتها التقنية الحالية أو عرض منتج بعينه أو علاقتها بنا. لهذه الأبعاد أدلة منفصلة.

## IAC 2026 — جناح الإمارات للفضاء

توثق [دراسة الجهات والعلاقات والفرضيات](../REGIONS/UAE/IAC_2026_PAVILION/README.md) 13 جهة سمّتها وزارة الخارجية الإماراتية ضمن جناح أنطاليا، 5–9 أكتوبر 2026، بمصادر أصلية وحدود معلنة. لا تضاف الأسماء تلقائياً إلى سجلات CABSAT/SATExpo الـ55.
