## Scope and methodology

The [UAE Ministry of Foreign Affairs](https://www.mofa.gov.ae/en/Missions/Ankara/Media-hub/News/7-10-2026-ankara) names **13 entities** at the UAE Space Pavilion during the [77th International Astronautical Congress (Antalya, 5–9 October 2026)](https://www.iafastro.org/events/iac/international-astronautical-congress-2026/). The announcement says **“and others”**: this is a named subset, **not** a complete exhibitor census. [The Arabic MoFA edition](https://www.mofa.gov.ae/ar-AE/Missions/Ankara/Media-hub/News/7-10-2026-ankara) corroborates the names. Participants include public bodies, research institutions, companies and **Dubai Airshow**, an exhibition organisation—not 13 commercial satellite suppliers.

The study tracks *actor → public capability description → evidenced relationships → uncertainty → possible narrow test*. **FACT** is bounded by the official roster/event record; **SOURCE CLAIM** attributes what an organisation reports; **HYPOTHESIS** is a question for investigation, **not** an existing interface or partnership; **UNKNOWN** lacks evidence. Every actor has a stable `E` ID. [Machine-readable public evidence snapshot](https://github.com/loaderxxx/Cosmic-Programm/blob/main/ATLAS/REGIONS/UAE/IAC_2026_PAVILION/ECOSYSTEM_DATA.json) contains source/relationship IDs and explicit limitations.

## Proposed smallest pilot — scope before claims

**Candidate question:** For one non-confidential space-data use case, who has publicly evidenced capabilities, which relationships are documented, which interfaces are assumed, and what would disprove the proposed system map?

**Required input:** a genuine question owner/reviewer; a scoped public/licensed source set; exclusions, rights to results and agreed evaluation baseline. **Method:** identity normalisation → dated source ledger → actor/capability matrix → verified source-attributed links vs hypotheses → contradictory evidence review. **Outputs:** reproducible register, capabilities matrix, relationship graph, open-gaps report and reviewer feedback. **Proposed acceptance:** every material claim is traceable; no hypothetical relationship presented as established; measure coverage/error against a reviewer-defined sample; record utility and analyst effort.

**Status:** proposed research exercise only. No commissioned pilot, delivery SLA, agency permission, funding, procurement, flight hardware or deployed software is claimed.
