## اقتراح تجربة بحثية محدودة

**السؤال المقترح:** في حالة استخدام واحدة غير سرية لبيانات الفضاء، ما الجهات والقدرات المؤيدة بمصادر، والعلاقات الموثقة، والواجهات المفترضة، وكيف نختبر صحة الخريطة؟

**المدخلات:** صاحب مشكلة ومراجع حقيقيان، ومصادر عامة أو مرخصة، وحدود استخدام البيانات، ومعيار تقييم متفق عليه. **الطريقة:** التحقق من أسماء الجهات ← تسجيل الأدلة وتواريخها ← مصفوفة القدرات ← التفريق بين الروابط المثبتة والفرضيات ← فحص الأدلة المناقضة. **المخرجات:** سجل قابل لإعادة الفحص، مصفوفة الجهات، خريطة الروابط، فجوات المعرفة، ورأي المراجع. **المعايير:** مصدر لكل ادعاء جوهري؛ صفر شراكات مفترضة تعرض كحقيقة؛ قياس الأخطاء والتغطية مقابل عينة متفق عليها؛ تقييم الفائدة والجهد.

**الحالة:** مقترح فقط، وليس مشروعاً متعاقداً عليه أو تجربة منفذة أو نظاماً معتمداً أو التزاماً بالموارد والتمويل.
