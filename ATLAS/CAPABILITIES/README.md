# خريطة القدرات

[الأطلس](../README.md) · [English](https://github.com/loaderxxx/Cosmic-Programm/blob/main/ATLAS/CAPABILITIES/README.md) · [Русский](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ru/ATLAS/CAPABILITIES/README.md) · [العربية](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ar/ATLAS/CAPABILITIES/README.md)

**ابدأ بالوظيفة المطلوبة، لا بالمورّد المفضّل.** ينظّم هذا التصنيف المخصّص للتصفّح القدرات التي تناقشها الأبحاث الصناعية العامة. وهو ليس مصفوفة تأهيل أو دليلاً على أن كل شركة مذكورة قادرة على توفير نظام كامل.

| المعرّف | عائلة القدرات | ما يجب أن تثبته المراجعة الهندسية |
|---|---|---|
| MISSION_SIM | محاكاة المهمات | نطاق النموذج وافتراضاته ودقته وقابليته للتكرار. |
| MISSION_C2 | قيادة المهمة والتحكم بها | صلاحيات الأوامر وملكية الحالة وحدود القياس عن بُعد والتعافي. |
| LINK_BUDGET | تحليل ميزانية الوصلة | الترددات والوحدات والفواقد والهوامش وافتراضات السيناريو. |
| NETWORK_ORCHESTRATION | تنسيق الشبكة وجدولة الاتصال | ملكية الموارد والأولويات والتعارضات وإعادة التخطيط. |
| GROUND_STATION | نظم المحطات الأرضية | مسؤوليات الهوائي وRF والتتبّع والمراقبة والواجهات. |
| GROUND_CLOUD | الخدمات الأرضية المُدارة | الوصول وواجهة الجدولة ومسارات البيانات وحدود الخدمة. |
| VSAT_BASEBAND | المودم وشبكات النطاق الأساسي | شكل الموجة وعائلة المحور ودعم الطرفيات وتوافق الإصدارات. |
| TERMINAL_ANTENNA | الهوائيات والطرفيات | التتبّع والتوجيه والنطاقات والبيئة والموافقات المنطبقة. |
| RF_HARDWARE | عتاد الترددات الراديوية | القدرة والضوضاء وعرض النطاق والموصلات وظروف التشغيل. |
| DIGITAL_IF | معالجة التردد الوسيط الرقمي | ملف الحزم والتوقيت والسياق وترميز العينات والنقل. |
| SATELLITE_OPERATOR | السعة والخدمات الساتلية | التغطية والمدار والسعة وتوافر الخدمة والنطاق التجاري. |
| EARTH_OBSERVATION | رصد الأرض والبيانات | الدقة وتكرار الرصد والتكليف والترخيص والجودة وحاجة المستخدم. |
| SYSTEMS_ENGINEERING | هندسة النظم | المتطلبات والواجهات والميزانيات والتحقق وضبط التكوين. |
| NETWORK_INTEGRATION | تكامل الشبكات | حدود المسؤوليات والمراقبة والتحويل عند العطل والدعم. |
| INDUSTRY_ASSOCIATION | المعرفة والمعايير الصناعية | نطاق الإرشاد أو العضوية أو الشهادة، دون افتراض اعتماد. |
| CYBER_MONITORING | الأمن والمراقبة | الأصول ونموذج التهديد وضبط الوصول والسجلات ومسؤولية الاستجابة. |

## كيف تستخدم الخريطة؟

لسؤال عن برمجيات المهمة، راجع سجلي Antaris وINTEGRASYS. ولخيارات الأنظمة الأرضية، راجع Calian وSatService وCelestia TTI وAWS. وللطرفيات وRF، راجع AvL وETL وسجلات المكونات. وللخدمات والبيانات، راجع المشغّلين وجهات رصد الأرض. هذه مسارات قراءة في [دليل الجهات](../ORGANIZATIONS/README.md)، لا اختيارات لمورّدين مفضّلين.

قد تغطي جهة واحدة عدة وظائف، وقد تتداخل جهتان جزئياً فقط. غياب وسم يعني أن القدرة لم تُثبت ضمن هذا البحث، وليس أنها غير موجودة لدى الجهة. لا تحوّل الخريطة البحثية المتفرقة إلى ترتيب لقوة المورّدين.

**الخطوة التالية:** اختر [خيار نظام](../SYSTEM_OPTIONS/README.md)، وحدّد الواجهة، وافحص المواصفات الأولية، واكتب أصغر اختبار يميّز البدائل. [خريطة المعرفة التقنية الأصلية](../../RESEARCH/PUBLIC_TECHNICAL_KNOWLEDGE_MAP.md) و[مصفوفة قدرات البرنامج](../../PROGRAM/ARCHITECTURE/CAPABILITY_MATRIX_v1.0.md) وثيقتان منفصلتان بلغاتهما الأصلية عن هندسة البرنامج، وليستا مجموعة بيانات لتأهيل الصناعة.
