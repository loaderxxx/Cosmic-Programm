## One organization, multiple contexts

An organization should have one stable identity record, linked to many capabilities, events and programmes. The existing P/C record IDs are preserved as provenance keys, not treated as proof of legal identity. New sources should enrich an existing record rather than create another copy for every exhibition.

**Evidence classes:** FACT, SOURCE CLAIM, USER CLAIM, ESTIMATE, INTERPRETATION, HYPOTHESIS and UNKNOWN. Private user claims and interaction records are not exposed here. Technical and relationship conclusions retain their own dates, source links and limitations.
