## جهة واحدة وسياقات متعددة

ينبغي أن تكون لكل جهة هوية سجل مستقرة مرتبطة بقدرات وفعاليات وبرامج متعددة. تُحفظ معرّفات P/C الأصلية بوصفها مفاتيح للمصدر، لا دليلاً على الهوية القانونية. يجب أن تثري المصادر الجديدة السجل القائم بدلاً من إنشاء نسخة لكل معرض.

**تصنيفات المعلومات:** FACT — حقيقة مدعومة؛ SOURCE CLAIM — تصريح مصدر؛ USER CLAIM — إفادة المستخدم؛ ESTIMATE — تقدير؛ INTERPRETATION — تفسير تحليلي؛ HYPOTHESIS — فرضية؛ UNKNOWN — أمر غير محسوم. لا تُكشف هنا إفادات المستخدم الخاصة أو سجلات التفاعل. وتحتفظ الاستنتاجات التقنية واستنتاجات العلاقات بتواريخها ومصادرها وقيودها.
