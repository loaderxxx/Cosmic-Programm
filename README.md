# Cosmic Programm 🚀

## Русская версия — основной вход

**Cosmic Programm** — независимая долгосрочная исследовательская программа о развитии деятельности людей и роботов за пределами Земли.

### Публичный принцип

Публичная версия содержит **результаты, выводы, исследования и материалы проекта**, но не раскрывает внутренние алгоритмы работы, приватные промпты, детальные методы обработки задач или другие защищённые элементы.
