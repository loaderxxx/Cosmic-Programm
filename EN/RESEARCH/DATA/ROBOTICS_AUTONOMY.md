# Robotics / Autonomy — Technical Dataset

## Capability chain

Perception -> localization -> mapping -> hazard detection -> planning -> guidance/control -> manipulation/mobility -> fault detection -> safe recovery.

## Capture for every system

- sensor suite
- compute architecture
- localization source
- communications dependency
- autonomy level
- operator workload
- navigation accuracy
- obstacle/hazard tolerance
- mobility mechanism
- manipulator payload
- operating temperature
- radiation environment
- failure modes
- recovery behaviour
- demonstrated autonomous operating time

NASA explicitly identifies autonomous systems and robotics as a Moon-to-Mars sub-architecture covering both software and hardware used during crewed and uncrewed periods.
