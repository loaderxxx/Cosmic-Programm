# Propulsion Master Dataset v1.0

## Public engineering baseline

### NASA RS-25 / SLS
SLS Block 1 uses four RS-25 engines in its core stage and two five-segment solid rocket boosters. NASA states a Block 1 payload capability of 27 metric tonnes to lunar space.

### ESA Vulcain 2.1
Vulcain 2.1 uses liquid oxygen and liquid hydrogen. ESA publishes 1,371 kN thrust, 468 s operating duration, consumption exceeding 327 kg/s, and a hydrogen turbopump running at 33,000 rpm and 15 MW. ESA also documents qualification hot-fire tests and integrated subsystem tests.

### Blue Origin BE-4
BE-4 is a liquefied-natural-gas engine using oxygen-rich staged combustion. Blue Origin publishes 2,846 kN sea-level thrust and deep-throttling capability. New Glenn uses seven BE-4 engines on its first stage.

### SpaceX Raptor / Starship
The public Starship guide describes a two-stage reusable system using subcooled methane and oxygen and includes preliminary payload-interface and environmental information. Values for a specific flight configuration must be versioned rather than treated as constants.

## Engineering conclusions

1. Engine performance is only one characteristic; thermal conditions, turbomachinery, ignition, control, manufacturing and qualification are equally important.
2. Propellant choice affects tanks, pressurization, thermal management, ground infrastructure and reuse.
3. Engine-test cadence is a capability of the entire programme.
4. Qualification evidence must be stored alongside headline thrust figures.
