# Time, Data and Provenance Master Dataset v1.0

## Purpose

Establish a common provenance principle for the programme's technical data.

## Minimum measurement record

- identifier;
- time;
- time scale;
- source;
- spacecraft;
- subsystem;
- sensor;
- configuration;
- units;
- raw value;
- processed value;
- processing algorithm;
- software version;
- quality;
- uncertainty.

## Provenance

Every published technical conclusion must allow the following chain to be traced:

**source → extraction → normalization → calculation/processing → result → programme document.**

## Versions

Changing an input parameter must not silently change an earlier conclusion. The earlier result is retained with its version and the reason for the change.

## Principle

Data without provenance does not become an engineering fact merely because it appears plausible.
