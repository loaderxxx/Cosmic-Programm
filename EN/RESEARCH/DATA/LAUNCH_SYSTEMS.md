# Launch Systems — Quantitative Dataset Schema

| System | Operator | Architecture | Propellant / propulsion | Reuse | Key public parameters | Source | Verified |
|---|---|---|---|---|---|---|---|
| SLS | NASA | Heavy-lift, expendable core architecture | Cryogenic core + solid boosters | Expendable launch stack | Deep-space crew/cargo architecture | NASA Artemis | 2026-09-19 |
| Falcon 9 | SpaceX | Two-stage | LOX/RP-1 | First-stage recovery/reuse | Commercial LEO/GTO launcher | SpaceX | 2026-09-19 |
| Starship/Super Heavy | SpaceX | Two-stage fully reusable target | LOX/CH4 | Full-system reuse target | 124 m, 9 m, 100+ t published payload target | SpaceX | 2026-09-19 |
| Ariane 6 | ESA/Arianespace | Modular two/four-booster launcher | Cryogenic core + solid boosters | Current configuration is not fully reusable | Four-booster configuration demonstrated in 2026 | ESA | 2026-09-19 |

This table is intentionally a seed dataset. Exact payload numbers must always be tied to orbit, mission profile and configuration; they should not be compared as a single universal number.
