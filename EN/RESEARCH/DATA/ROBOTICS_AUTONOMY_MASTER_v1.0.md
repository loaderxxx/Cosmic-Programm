# Robotics and Autonomy Master Dataset v1.0

## Autonomy levels

### Level 0
All commands are specified by the operator.

### Level 1
Automatic execution of predefined sequences.

### Level 2
Automatic detection of a limited set of faults and transition to safe mode.

### Level 3
Autonomous navigation, local-action planning and recovery.

### Level 4
Independent execution of mission tasks with limited operator intervention.

### Level 5
Autonomous adaptation to an unknown environment within predefined safety boundaries.

## Subsystems

- computer;
- sensors;
- actuators;
- state estimation;
- navigation;
- planner;
- fault detection/isolation;
- safe modes;
- payload management;
- logging;
- operator communications.

## Cosmic

The first demonstrator must measure specific verifiable functions rather than an “autonomy level”:
- fault detection;
- transition to safe mode;
- recovery;
- an autonomous sequence;
- communications loss;
- communications restoration;
- sensor degradation;
- power limitation.

Every function must have a test scenario.
