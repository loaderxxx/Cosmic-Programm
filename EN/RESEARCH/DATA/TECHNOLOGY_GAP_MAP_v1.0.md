# Cosmic Programm Technology Gap Map v1.0

## Class A — mission uncertainty

- final orbit for the first mission;
- exact payload;
- required duration;
- communications requirements;
- radiation environment;
- thermal environment.

## Class B — engineering maturity

- autonomous fault management;
- compact power system;
- reliable communications;
- high-precision attitude control;
- autonomous navigation;
- thermal-vacuum qualification;
- software/hardware integration.

## Class C — lunar technologies

- landing navigation;
- operation in a dusty environment;
- surface power;
- long-duration energy storage;
- surface communications;
- autonomous mobility;
- resource prospecting.

## Class D — scaling

- repeatable manufacturing;
- standardized interfaces;
- qualification of series-production spacecraft;
- spare elements;
- launching multiple missions;
- compatibility between equipment generations.

## Prioritization rule

A gap receives high priority not because it is difficult, but when it:
1. blocks the next mission;
2. carries high risk;
3. takes a long time to verify;
4. generates data useful for many future missions.
