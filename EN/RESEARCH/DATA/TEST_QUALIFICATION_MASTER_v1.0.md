# Testing and Qualification Master Dataset v1.0

## Qualification stack

### Component
Materials/process verification, functional tests and environmental screening.

### Subsystem
Functional performance, electrical compatibility, thermal and mechanical tests.

### Integrated system
End-to-end tests of commands/telemetry, software, autonomy, power and fault response.

### External environment
Thermal-vacuum, vibration, acoustics, shock, radiation where required and electromagnetic compatibility.

### Operational rehearsal
Ground-segment simulation, countdown rehearsals, emergency procedures and mission-control training.

### Flight
Comparison of actual telemetry against predictions, anomaly investigation and model updates based on flight results.

## Verification philosophy

Testing is not just a final acceptance gate. Test data changes the model, and the updated model changes the next design iteration.

## Cosmic requirement

Every significant subsystem introduced into flight for the first time must have a documented verification plan before the hardware is declared flight-ready.
