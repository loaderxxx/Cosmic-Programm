# Cosmic Programm Mission Dependency Graph v1.0

## Baseline chain

Knowledge and requirements
→ orbital demonstrator
→ verified autonomy/communications/power
→ lunar resource prospecting
→ validated environmental data
→ infrastructure demonstrator
→ repeatable logistics
→ resource processing
→ permanent infrastructure
→ Mars precursors.

## Critical dependencies

### Orbital demonstrator
Depends on:
- launch-vehicle selection;
- payload interface;
- mass budget;
- power budget;
- radio link;
- ground segment;
- qualification plan.

### Lunar scout
Additionally depends on:
- navigation;
- thermal model;
- radiation model;
- lunar communications;
- landing/transport solution.

### Infrastructure demonstrator
Additionally depends on:
- a validated environment;
- long-duration power;
- dust protection;
- communications reliability;
- autonomous health management.

## Rule

Progression to the next stage cannot be based solely on the successful launch of the preceding spacecraft. Progression requires closing specific technical dependencies and obtaining the data for which the stage was created.
