# Capability Readiness Matrix v1.0

## Purpose

Connect programme architecture with the actual evidence supporting its capabilities.

## Levels

**L0 — idea:** the function is described.

**L1 — analysis:** physical feasibility is supported by calculation.

**L2 — laboratory:** the function is demonstrated under controlled conditions.

**L3 — integration:** the function works together with other subsystems.

**L4 — flight-like:** the function is tested under conditions close to operations.

**L5 — space demonstration:** the function is confirmed in actual space conditions.

**L6 — repeatable operations:** the function is confirmed by more than one operational implementation.

## Application

For each capability, record:
- current level;
- evidence;
- uncertainty;
- next experiment;
- dependent missions;
- conditions for advancement.

## Rule

A capability's readiness level must not be inferred solely from the maturity of one component. The readiness of the function in its system context matters.
