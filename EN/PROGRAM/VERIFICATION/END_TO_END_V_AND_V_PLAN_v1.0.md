# End-to-End Verification and Validation Plan v1.0

## Objective

Connect programme requirements with testing, simulation and operational data.

## Levels

### Analysis
Verification through calculations, models and engineering estimates.

### Component verification
Functional and parametric testing of individual components.

### Subsystem
Verification of component interaction.

### System
Verification of the complete spacecraft.

### End-to-end system
Spacecraft + ground segment + communications links + software + operational scenario.

### Operations
Verification through actual flight results.

## For each requirement

Record:

**REQ-ID → V&V method → equipment/model → input conditions → procedure → measurement → criterion → result → evidence → status.**

## Method types

- INSPECTION;
- ANALYSIS;
- TEST;
- DEMONSTRATION;
- FLIGHT DATA.

## Rule

A requirement cannot be closed merely by citing a similar system from another organization. An external system may provide a baseline, but Cosmic Programm compliance requires its own applicability verification.

Status: BASELINE.
