# EMC/EMI Framework v1.0

## Purpose

Prevent a situation in which individual subsystems pass tests independently but become incompatible after integration.

## Interference sources

- transmitters;
- power electronics;
- DC/DC converters;
- motors and drives;
- digital computers;
- clock generators;
- cable harnesses;
- external sources.

## Susceptible elements

- sensors;
- receivers;
- high-speed links;
- analogue measurement circuits;
- timing systems;
- ADCS;
- memory.

## Control

Record:
- emission levels;
- susceptibility;
- conducted interference;
- radiated interference;
- grounding;
- shielding;
- filtering;
- cable routing;
- compatibility between operating modes.

## Verification

Perform analysis early, followed by EMC/EMI testing at subsystem and integrated-system levels.
