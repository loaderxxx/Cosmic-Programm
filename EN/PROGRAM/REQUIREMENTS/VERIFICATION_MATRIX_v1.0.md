# Verification Matrix v1.0

| Area | Verification method | Evidence |
|---|---|---|
| Structure | analysis + inspection + qualification testing | loads, margins of safety, test report |
| Thermal control | analysis + thermal-vacuum testing | thermal-model correlation |
| Power | analysis + functional test | generation/storage/load budget |
| Communications | analysis + RF test | radio link, BER/data rate |
| Attitude control | analysis + HIL/system test | accuracy and stability data |
| Navigation | simulation + testing + flight | navigation-error budget |
| Autonomy | software tests + HIL + fault injection | recovery results |
| Payload interface | inspection + mechanical/electrical tests | ICD compliance |
| Software | unit/integration/system tests | requirements coverage |
| Ground segment | end-to-end demonstration | command/telemetry/data flow |
| Launch-vehicle integration | fit check + interface test | launch-vehicle ICD compliance |
| Operations | simulation + rehearsal | procedures and contingency scenarios |
| Flight performance | telemetry + post-flight analysis | measured versus predicted performance |

Requirement closure requires objective evidence corresponding to the selected verification method.
