# Mission A — Test Campaign v1.0

## Objective

Build a test sequence that reduces uncertainty before flight, rather than merely confirming functionality after assembly.

## Campaign

### T0 — analysis
- requirements;
- interfaces;
- budgets;
- FDIR;
- worst-case environments.

### T1 — component
- power;
- computing;
- communications;
- sensors;
- actuators.

### T2 — subsystem
- ADCS;
- EPS;
- communications;
- flight software;
- payload.

### T3 — HIL
Connect real components to a simulated environment.

### T4 — integrated system
Verify nominal and fault scenarios.

### T5 — environmental
Verify vibration, thermal-vacuum and applicable EMC/EMI requirements.

### T6 — end-to-end
Spacecraft + ground segment + command + telemetry + data analysis.

## Output

Every test must have a procedure, input conditions, an expected result, measurements and an unambiguous PASS/FAIL criterion.

Status: BASELINE FRAMEWORK.
