# Mission A — CONOPS v1.0

## Purpose

The orbital autonomy and logistics demonstrator should provide verifiable data on the integrated operation of computing, communications, power, attitude control and autonomous control.

## Phases

1. launch and separation;
2. initial stabilization;
3. deployment;
4. power-system checkout;
5. communications checkout;
6. state determination;
7. nominal autonomous operation;
8. controlled fault scenarios;
9. transmission of results;
10. mission completion.

## Principal demonstrations

- autonomous mode switching;
- operation with delayed commands;
- recovery from a simulated fault;
- data-transmission scheduling;
- power-consumption management;
- validation of the interface for future payloads.

## Result criterion

The result is not the spacecraft's presence in orbit, but a reproducible set of measurements with configuration, time reference and a description of the experimental conditions.
