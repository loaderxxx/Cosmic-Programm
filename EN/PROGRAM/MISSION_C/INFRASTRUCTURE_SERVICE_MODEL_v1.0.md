# Mission C — Infrastructure Service Model v1.0

## Purpose

Treat the lunar pathfinder as a node of future infrastructure, not an isolated spacecraft.

## Services

- power;
- communications;
- navigation data;
- computing;
- payload hosting;
- diagnostics;
- temporary data storage;
- mechanical interface;
- preparation for the next cargo delivery.

## Metrics

For each service, record:
- availability;
- power;
- throughput;
- latency;
- service life;
- fault tolerance;
- cost of provision;
- scalability.

## Principal question

Which characteristics of one node make adding a second node easier, cheaper or more functionally useful?
