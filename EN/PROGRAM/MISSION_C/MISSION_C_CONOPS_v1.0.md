# Mission C — CONOPS v1.0

## Purpose

The lunar infrastructure pathfinder tests long-duration operation of a modular node: power, communications, navigation, computing, autonomy and payload.

## Phases

1. delivery;
2. landing/deployment;
3. commissioning;
4. power-system checkout;
5. communications checkout;
6. autonomous operation;
7. payload operation;
8. hot/cold transitions;
9. fault scenarios;
10. servicing/reconfiguration;
11. preparation for the next cargo delivery.

## Principal outcome

Create a measurement-based foundation for repeated delivery and infrastructure expansion.

## Key principle

Mission C should be designed not as an isolated experiment but as the first element in a repeatable sequence.
