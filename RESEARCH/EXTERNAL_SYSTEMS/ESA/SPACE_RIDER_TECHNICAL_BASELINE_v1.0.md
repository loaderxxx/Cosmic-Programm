# ESA Space Rider — Technical Baseline v1.0

## System role
Reusable uncrewed orbital laboratory and re-entry platform.

## Architecture
Two principal sections:
- orbital module
- re-entry module

## Public mission profile
ESA describes up to two months in orbit.

## Payload environment
The official User Guide covers:
- payload services
- mission scenarios
- communications protocols
- daily data-download capability
- acceleration
- humidity during transport/launch
- radiation
- final interfaces
- working environments
- payload integration
- ground control
- landing operations
- mission timeline

## Engineering lesson
A user guide can turn a spacecraft into a service platform by exposing stable payload interfaces and environmental constraints.
