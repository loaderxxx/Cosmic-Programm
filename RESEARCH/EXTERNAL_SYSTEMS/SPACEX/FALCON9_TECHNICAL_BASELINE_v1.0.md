# SpaceX Falcon 9 — Technical Baseline v1.0

## System role
Reusable commercial orbital launcher.

## Public parameters
- height: 70 m
- diameter: 3.7 m
- mass: 549,054 kg
- LEO payload: 22,800 kg
- GTO payload: 8,300 kg
- Mars payload: 4,020 kg

## Propulsion
First stage: nine Merlin engines, LOX/RP-1.
Merlin public thrust: 845 kN per engine.
First-stage architecture includes recovery hardware and is designed for reuse.

## Payload operations
SpaceX provides a Falcon User's Guide. Technical extraction should cover payload envelope, environments, interfaces, mission integration, separation, telemetry and rideshare.

## Engineering lessons
- standardized launch service
- reusable first-stage operations
- production/recovery integrated with launch cadence
- customer-facing technical interface documentation

## Primary source
SpaceX Falcon 9 and Falcon User's Guide.
