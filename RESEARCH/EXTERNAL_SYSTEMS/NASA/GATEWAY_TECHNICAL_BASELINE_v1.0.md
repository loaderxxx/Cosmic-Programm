# NASA Gateway — Technical Baseline v1.0

## System role
Modular cislunar infrastructure supporting crew transfer, science, communications, logistics and future lunar/Mars operations.

## Architecture
Gateway is assembled from modules and international/commercial contributions rather than being one monolithic spacecraft.

## Functions
- crew habitation/support
- docking
- logistics
- communications
- science
- staging for lunar surface missions
- technology demonstration

## Engineering principle
A persistent cislunar node moves mission architecture from point-to-point expeditions toward reusable logistics.

## Documentation targets
Extract module mass/power, propulsion, docking standards, communications, radiation, thermal design, logistics interfaces, autonomous/remote operations, crew duration and design lifetime.
