# NASA Human Landing Systems — Technical Baseline v1.0

## System role
Transport astronauts from lunar orbit to the lunar surface and back.

## Current architecture
NASA's HLS programme uses commercial providers. NASA currently identifies SpaceX for Artemis III/IV and Blue Origin for Artemis V.

## Mission sequence
SLS -> Orion -> lunar orbit -> HLS transfer -> lunar descent -> surface stay -> ascent -> lunar-orbit rendezvous -> Orion/Gateway transfer.

## System requirements themes
- crew safety
- lunar-orbit rendezvous/docking
- precision landing
- surface habitation
- EVA support
- ascent
- communications
- navigation
- thermal control
- contingency operations

## Large cargo direction
NASA also documents large cargo delivery landers, showing that lunar landing capability can become logistics infrastructure rather than only a crew vehicle.
