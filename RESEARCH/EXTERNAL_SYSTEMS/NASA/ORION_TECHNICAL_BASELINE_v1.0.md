# NASA Orion — Technical Baseline v1.0

## System role
Crew spacecraft for deep-space missions in the Artemis architecture.

## Major elements
- Crew Module
- European Service Module
- Launch Abort System
- avionics and guidance
- environmental control/life support
- power
- propulsion
- communications
- thermal protection

## Mission functions
Launch with SLS -> translunar flight -> lunar-orbit operations / rendezvous -> crew support -> return trajectory -> high-energy Earth re-entry -> recovery.

## Engineering focus
Orion is not simply a capsule. It is a deep-space crew system coupled to SLS, Gateway/HLS interfaces, ground operations and recovery.

## Technical documentation targets
Extract mass, consumables, power, thermal protection, propulsion, crew volume, communications, docking, abort modes, re-entry loads, landing system and qualification evidence from NASA reference documentation.

## Primary source
NASA Orion reference documentation.
