# Communications / Navigation — Technical Dataset

## Architecture layers

1. Ground stations and terrestrial networks
2. Earth-orbit relay/communications constellations
3. Cislunar relay infrastructure
4. Direct spacecraft-to-Earth links
5. Optical communications
6. Navigation and timing
7. Autonomous relative navigation
8. Surface communications networks

## Technical parameters to capture

- frequency / optical band
- data rate
- link distance
- antenna aperture
- terminal mass
- power
- pointing accuracy
- latency
- availability
- redundancy
- relay architecture
- navigation accuracy
- environmental constraints
- demonstrated flight performance

NASA explicitly identifies Communications and Positioning, Navigation, and Timing as one of the 12 Moon-to-Mars sub-architectures. This makes communications/navigation an architectural dependency, not a secondary subsystem.
