# Марсианский EDL v1.0

## Цепочка

entry → thermal protection → aerodynamic deceleration → guidance → terminal descent → landing → surface activation.

## Основные ограничения

- атмосфера;
- масса;
- баллистический коэффициент;
- тепловая нагрузка;
- парашютная применимость;
- propulsion;
- terrain hazards;
- landing dispersion;
- communications delay;
- autonomous decision making.

## Верификация

Комбинировать:
- atmospheric simulation;
- trajectory Monte Carlo;
- thermal analysis;
- hardware tests;
- drop/free-flight tests где применимо;
- integrated software/hardware simulation;
- flight data.

## Связь с программой

Mars EDL должен быть отдельным технологическим треком задолго до первой крупной марсианской миссии.
