# Сводная база космических сред v1.0

## Назначение

Единый слой требований к физической среде для сравнения орбитальных, лунных и дальних миссий.

## Среды

### Орбита Земли
- вакуум;
- атомарный кислород для применимых высот;
- радиация;
- термические циклы;
- микрометеороиды и орбитальный мусор;
- динамические нагрузки.

### Луна
- вакуум;
- экстремальные температурные циклы;
- реголит;
- пыль;
- радиация;
- микрометеороиды;
- низкая гравитация;
- длительные периоды освещения/темноты.

### Дальний космос
- радиационная среда;
- солнечная радиация;
- задержка связи;
- ограниченная доступность энергии;
- длительная автономность;
- отсутствие возможности быстрого физического обслуживания.

## Параметры для каждого сценария

**среда → диапазон → длительность → источник → неопределённость → влияние на подсистемы → метод проверки.**

## Принцип

Среда должна входить в требования до выбора компонентов, а не использоваться как проверка после проектирования.

Статус: BASELINE FRAMEWORK.
