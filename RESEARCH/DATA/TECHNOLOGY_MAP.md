# Global Space Technology Map

## Transportation
Launch vehicles -> orbital transfer -> cislunar transfer -> lunar landing -> surface mobility -> Mars transfer -> Mars landing.

## Energy
Chemical propulsion -> solar power -> batteries -> regenerative/fission concepts -> surface power networks.

## Information
Ground networks -> relay satellites -> optical/radio links -> autonomous navigation -> distributed data systems.

## Autonomy
Guidance/navigation/control -> hazard detection -> autonomous landing -> surface robotics -> crew-assistance systems -> autonomous infrastructure operations.

## Resources
Consumable delivery -> recycling -> local water/oxygen extraction -> construction feedstocks -> progressively closed-loop logistics.

## Industrialization
Launch cadence -> mass manufacturing -> reusable transport -> orbital assembly -> lunar surface infrastructure -> resource utilization -> deep-space logistics.

## Research priority
Each technology should eventually receive quantitative fields for mass, power, throughput, energy efficiency, lifetime, maturity, dependency chain, test evidence and interface requirements.
