# Technical Documentation Library

This directory indexes authoritative technical documentation for external space programmes.

We do not copy entire copyrighted manuals. We store document metadata, official source links, scope, extracted engineering facts with provenance, technical notes, and cross-links. Original manuals remain at their authoritative publishers.

Documentation classes:
- programme architecture
- system reference guides
- spacecraft user guides
- launcher user guides
- interface/control documents
- communications ConOps
- avionics/software architecture
- mission operations
- qualification/testing
- payload integration
- environmental requirements
- technology/data-gap documents

Priority source families: NASA SLS/Artemis/Gateway/HLS/Moon-to-Mars; ESA Ariane 6/Argonaut/Space Rider; SpaceX Starship/Falcon 9. Expand to CNSA, JAXA, ISRO, Roscosmos and commercial providers.

Extraction priority: mass/propellant/power; interfaces; communications; avionics/software; environmental constraints; testing/qualification; operations; failure modes; technology gaps; industrial structure.
