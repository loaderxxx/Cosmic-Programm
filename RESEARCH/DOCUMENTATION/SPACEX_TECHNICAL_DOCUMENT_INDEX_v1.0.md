# SpaceX — External Technical Documentation Index v1.0

## Starship Users Guide
SpaceX's Starship Users Guide describes the reusable two-stage architecture, payload accommodation, mechanical interfaces, payload environments and preliminary mass-to-orbit capabilities.
Official document: https://www.spacex.com/media/starship_users_guide_v1.pdf

## Starship official vehicle documentation
Current public vehicle page covers vehicle architecture, dimensions, propellant, engines, reuse, lunar/Mars roles and refuelling concepts.
Official source: https://www.spacex.com/vehicles/starship/

## Falcon 9 technical documentation
Official vehicle documentation covers dimensions, mass, payload capabilities, first-stage propulsion/recovery, second stage, fairing and rideshare.
Official source: https://www.spacex.com/vehicles/falcon-9/

## Falcon User's Guide
The Falcon User's Guide is the primary customer-facing technical source for payload integration, environments, interfaces and mission constraints. It should be extracted separately rather than summarized only from the marketing page.
