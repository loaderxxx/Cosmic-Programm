# NASA — External Technical Documentation Index v1.0

## Purpose
Catalogue primary technical documents that should be mined into the Cosmic Programm technical database.

## SLS Reference Guide
NASA publishes Artemis I and Artemis II SLS Reference Guides covering design, capabilities, major components, manufacturing, testing, assembly and launch activities.
Official source: https://www.nasa.gov/humans-in-space/space-launch-system/reference-guide/

The current page lists an 82-page Artemis II guide and an 86-page Artemis I guide.

## Orion Reference Guide
Covers the Crew Module, European Service Module, Launch Abort System, life support, power, propulsion, crew systems, mission operations and deep-space return.
Official source: https://www.nasa.gov/reference/orion-spacecraft/

## SLS Avionics
Covers booster/core avionics, flight computers, software, engine controllers, integration and verification.
Official source: https://www.nasa.gov/reference/sls-avionics/

## SLS Block 1B
Covers Exploration Upper Stage, Universal Stage Adapter, cargo configuration, performance increase and testing.
Official source: https://www.nasa.gov/reference/sls-space-launch-system-block-1b/

## Human Landing Systems
Covers crew and cargo lunar landers, docking, lunar-orbit transfer, surface operations and future Gateway integration.
Official source: https://www.nasa.gov/reference/human-landing-systems-2/

## Gateway
Covers modular cislunar infrastructure, crew operations, communications, logistics and interoperability.
Official source: https://www.nasa.gov/gateway-capabilities/

## HLS RF Communications ConOps
Formal communications concept for HLS, Earth, Gateway, suits and lunar surface systems.
Official source: https://ntrs.nasa.gov/citations/20250003508

## Moon-to-Mars Architecture Definition Documents
Master architecture set with technology and data gaps.
Official source: https://www.nasa.gov/moontomarsarchitecture-architecturedefinitiondocuments/

## Extraction plan
For each source extract: system hierarchy, mass, dimensions, power, propulsion, consumables, interfaces, environments, communications, avionics, software, operations, test/qualification, failure constraints, technology gaps and suppliers.
