# Blue Origin — External Technical Documentation Index v1.0

## New Glenn
Blue Origin describes New Glenn as a reusable orbital launch vehicle. The current public page states a first-stage design for a minimum of 25 flights, a 7 m payload fairing, more than 13 metric tons to GTO and 45 metric tons to LEO, with two BE-3U upper-stage engines.
Official source: https://www.blueorigin.com/new-glenn

## Payload User Guide
Blue Origin provides a payload user's guide through its customer interface. This should be treated as the primary source for detailed payload integration requirements when available.
Official source: https://www.blueorigin.com/new-glenn/fly-a-payload-on-new-glenn

## Artemis / Blue Moon
NASA's HLS documentation identifies Blue Origin as the provider developing the crewed Blue Moon HLS for Artemis V and notes cargo variants for delivery of large infrastructure to the lunar surface.
NASA source: https://www.nasa.gov/reference/human-landing-systems-2/
