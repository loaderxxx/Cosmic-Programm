# Global Space Programs — Structured Research Database

This directory converts the global space-program technical baseline into a structured research database.

## Public/private boundary

PUBLIC: documented technical facts, architectures, hardware, interfaces, mission profiles, quantitative parameters, technologies, dependencies, test results, and cited conclusions.

PRIVATE CORE: internal Cosmic Programm reasoning algorithms, proprietary prompts, decision-processing procedures, hidden methodologies, protected implementation details, and confidential partner information.

## Program dossier standard

Each program dossier should capture:
- scope and objectives
- current status and dated milestones
- launch systems
- spacecraft and landers
- propulsion
- power
- communications and navigation
- autonomy and robotics
- habitation and life support
- surface mobility
- ISRU/resource utilization
- logistics and interfaces
- testing and qualification
- quantitative parameters
- technology dependencies
- open technical risks
- primary sources
- last verified date
