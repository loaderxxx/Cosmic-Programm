# Build / Buy Matrix v0.1

| Capability | Initial strategy | Reason |
|---|---|---|
| Orbital launch | BUY | Mature commercial service exists |
| Lunar launch/landing | BUY/PARTNER | Avoid early capital-heavy vertical integration |
| Spacecraft bus | BUY/PARTNER + integration | Use mature components |
| Autonomy software | BUILD/OWN | Strategic differentiated capability |
| Payload architecture | BUILD/OWN | Directly creates mission-specific value |
| Data architecture | BUILD/OWN | Reusable across missions |
| Modular interfaces | BUILD/OWN | Creates vendor flexibility |
| Resource intelligence | BUILD/OWN | Accumulates proprietary mission knowledge |
| Ground operations | BUILD/INTEGRATE | Core operational competence |
| Power subsystem | PARTNER/BUY initially | Mature technology |
| Communications | BUY/PARTNER | Commodity where requirements permit |
| ISRU hardware | PARTNER/BUILD | Develop only against validated resource target |
| Launch vehicle | BUY initially | Defer major propulsion capital commitment |

## Principle
Own the architecture, interfaces, data and mission-critical intellectual property before attempting to own every physical layer.
