# Каркас надёжности и FDIR v1.0

## Назначение

FDIR: обнаружение отказа, изоляция отказа и восстановление.

## Цепочка

**наблюдение → обнаружение аномалии → классификация → изоляция → переход в безопасное состояние → восстановление → подтверждение результата.**

## Классы отказов

- датчик;
- исполнительный орган;
- питание;
- вычислитель;
- память;
- связь;
- перегрев;
- радиационное событие;
- программная ошибка;
- механическая деградация.

## Для каждого отказа

Фиксировать:
- симптом;
- источник данных;
- время обнаружения;
- ложноположительные условия;
- допустимое время реакции;
- действие FDIR;
- остаточную функциональность;
- способ восстановления.

## Безопасные состояния

Безопасный режим должен иметь явно определённые:
- потребление энергии;
- ориентацию;
- связь;
- минимальный набор активных систем;
- условия выхода;
- ограничения на автономные действия.

## Верификация

Каждый критический сценарий должен быть воспроизведён в модели или на испытательном стенде, а при возможности — в интегрированной системе.

Статус: FRAMEWORK.
