# Каркас теплового и радиационного анализа v1.0

## Тепловая модель

Каждый аппарат должен анализироваться минимум в сценариях:
- worst-case hot;
- worst-case cold;
- максимальная генерация тепла;
- минимальная генерация тепла;
- переходные режимы;
- запуск/развёртывание;
- безопасный режим;
- потеря части энергосистемы.

Для каждого узла фиксировать допустимый диапазон температур, рабочий диапазон и пределы хранения.

## Источники тепла

Учитывать:
- электронику;
- вычислители;
- передатчики;
- приводы;
- батареи;
- силовую электронику;
- полезную нагрузку;
- внешнее излучение;
- альбедо;
- планетарное инфракрасное излучение;
- внутренние тепловые связи.

## Тепловой бюджет

Разделять:
**поступление → поглощение → генерация → проводимость → излучение → накопление.**

Нельзя считать среднюю температуру достаточной характеристикой: критичны локальные горячие/холодные точки и переходные процессы.

## Радиация

Рассматривать отдельно:
- суммарную поглощённую дозу;
- одиночные события;
- заряженные частицы;
- солнечные события;
- trapped radiation;
- чувствительность электроники.

Для каждого критического компонента определить требуемый уровень защиты и допустимую деградацию.

## Верификация

Требуются:
- тепловые расчёты;
- thermal balance;
- thermal-vacuum;
- hot/cold функциональные испытания;
- радиационная квалификация или обоснование эквивалентности;
- анализ worst-case.

Статус: FRAMEWORK.
