# Cosmic Programm — Capability Dependency Graph v0.1

## Level 0 — Earth
Commercial launch -> spacecraft integration -> ground operations.

## Level 1 — Orbit
Power -> communications -> autonomy -> payload operations -> fault recovery.

## Level 2 — Cislunar
Deep-space communications -> navigation -> thermal management -> long-duration autonomy -> transfer operations.

## Level 3 — Lunar surface
Landing -> power -> communications -> thermal survival -> surface mobility -> resource sensing.

## Level 4 — Infrastructure
Persistent power -> persistent communications -> standardized interfaces -> logistics -> resource processing.

## Level 5 — Industrial precursor
Resource extraction -> storage -> consumables -> manufacturing feedstock -> repeat logistics.

## Level 6 — Mars precursor
Long-duration habitation -> surface power -> EDL -> ISRU -> autonomous logistics -> crew systems.

## Dependency rule
A capability is not considered mature because a subsystem works in isolation. It becomes mature when its interfaces, environmental assumptions, operational procedures and failure recovery have been demonstrated in an integrated system.
