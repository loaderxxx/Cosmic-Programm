# من البحث إلى التجارب الأولية

[الرئيسية](../README.md) · [English](https://github.com/loaderxxx/Cosmic-Programm/blob/main/PILOTS/README.md) · [Русский](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ru/PILOTS/README.md) · [العربية](https://github.com/loaderxxx/Cosmic-Programm/blob/lang/ar/PILOTS/README.md)

**الحالة: مفاهيم بحثية وهندسية مقترحة. لا تثبت هذه الصفحة وجود تجربة أولية مكتملة.** الهدف تصغير البرهان التالي وتوضيحه، لا إعادة تسمية مفهوم باعتباره قدرة منشورة.

## Mission A — التشغيل والاستقلالية

يتناول المفهوم القائم الاستقلالية واللوجستيات المدارية. وقد تكون الخطوة البحثية الأولى المناسبة سيناريو محلياً غير متصل لجلسات أرضية وتعافٍ: مدخلات اصطناعية، وملكية موارد صريحة، وقاعدة جدولة مرجعية، وعطل واحد، وسجل أحداث قابل للتكرار. يجب الاتفاق على معايير القبول والمراجعة المستقلة قبل تسمية العمل تجربة مشتركة مع شريك.

[مفهوم تشغيل Mission A](../PROGRAM/MISSION_A/MISSION_A_CONOPS_v1.0.md) · [المتطلبات](../PROGRAM/MISSION_A_SYSTEM_REQUIREMENTS_v0.1.md) · [حملة الاختبارات](../PROGRAM/MISSION_A/MISSION_A_TEST_CAMPAIGN_v1.0.md).

## Mission B — معلومات الموارد القمرية

يدرس المفهوم البيانات البيئية والمواردية اللازمة للقرارات الهندسية اللاحقة. الدراسة المكتبية أو تمرين البيانات ليسا دليلاً على حمولة قمرية أو قدرة هبوط أو مورد قابل للوصول.

[مفهوم Mission B](../PROGRAM/MISSION_B/MISSION_B_CONOPS_v1.0.md) · [نموذج بيانات الموارد](../PROGRAM/MISSION_B/LUNAR_RESOURCE_DATA_MODEL_v1.0.md).

## Mission C — بنية تحتية معيارية

يفحص المفهوم الطاقة والاتصالات واستضافة الحمولات ونمو عقدة بنية تحتية. ويعتمد على متطلبات وواجهات وموارد وقدرات تمكينية متحققة؛ وليس برنامج طيران معلناً.

[مفهوم Mission C](../PROGRAM/MISSION_C/MISSION_C_CONOPS_v1.0.md) · [نموذج الخدمة](../PROGRAM/MISSION_C/INFRASTRUCTURE_SERVICE_MODEL_v1.0.md).

## الحد الأدنى لاتفاق التجربة

تحديد مالك المشكلة، وسؤال الاختبار، والمدخلات المسموحة، والمنهج المرجعي، والناتج المقاس، وقاعدة النجاح أو الفشل، والمراجع، وحد الموارد وحقوق النتائج. تُستبعد قيادة الطيران وإرسال RF والخدمات المدفوعة والمشتريات والالتزامات الخارجية ما لم تُصرّح بها موافقة مستقلة.

[قارن خيارات النظم الصناعية](../ATLAS/SYSTEM_OPTIONS/README.md) · [ناقش سؤالاً محدوداً](../COLLABORATE.md). تحتفظ الوثائق التقنية القائمة بلغاتها وتواريخها الأصلية؛ ولم تُترجم المجموعة الهندسية التاريخية بالكامل.
