# Cosmic Programm — Public / Private Knowledge Separation

Cosmic Programm is currently a public research program with a protected private counterpart:

**Public:** `loaderxxx/Cosmic-Programm`  
**Private:** `loaderxxx/Cosmic-Programm-Private-Core`

## Strategic intelligence algorithm

**DISCOVER → COLLECT → CLASSIFY → ANALYZE → COMPARE → EXTRACT LESSONS → IDENTIFY GAPS → IMPROVE COSMIC PROGRAMM → TEST → VERIFY → CAPTURE**

We continuously study publicly and lawfully accessible space programs, missions, technologies, architectures and serious initiatives. Their lessons are inputs to independent improvement of Cosmic Programm.

Studying a public program does not authorize copying protected material, and external claims must retain provenance.

## Separation rule

**PUBLIC** may contain:
- public sources and citations;
- approved analyses;
- sanitized architectures;
- publishable experiments and results.

**PRIVATE CORE** contains, where appropriate:
- original unpublished knowledge;
- novel architecture or engineering methods;
- proprietary algorithms/models;
- unpublished experiments and datasets;
- potentially protectable IP;
- commercially sensitive strategy/economics;
- sensitive collaboration information.

## Publication gate

Nothing moves from Private Core to Public automatically.

**CLASSIFY → NOVELTY/IP REVIEW → SECURITY REVIEW → PRIVACY/CONFIDENTIALITY REVIEW → SANITIZE → HUMAN APPROVAL → PUBLISH**

If uncertain, keep the material private until reviewed.

## Derived knowledge rule

A result can become Private Core even when every input source was public if the synthesis creates original, unpublished and potentially valuable knowledge.

## Research ethics

Use only public and lawfully accessible information. Never seek or use leaked, stolen, hacked or unauthorized information.

## Provenance

For material original results preserve:
**ORIGIN → DATE → CONTRIBUTORS → SOURCES/INPUTS → VERSION → EXPERIMENT → EVIDENCE → DISCLOSURE STATUS → DECISION**

## Human control

The human project owner has final authority over publication, external disclosure, IP strategy and irreversible changes.
